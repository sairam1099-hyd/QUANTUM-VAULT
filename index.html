HOW TO PLAY & QUANTUM THEORY

1. OBJECTIVE

One hidden Quantum Core is concealed inside one of the 16 nodes (|0000⟩ to |1111⟩).

2. AMPLIFY ⚡

Each Amplify runs one Grover iteration (Oracle + Diffusion), boosting the hidden Core's probability.

3. WATCH

Observe the glowing nodes and trajectory graph as probability concentrates.

4. DON'T OVERSHOOT

More is not always better! At iteration 3 probability peaks (~96%). Iteration 4 drops back down.

5. MEASURE ◉

When you feel the probability is high enough, press Measure to sample a state.

6. WIN

If the measured node holds the Core, you win! Build a winning streak and aim for maximum score.

Grover's Amplitude Amplification

Provides a quadratic speedup for search ($O(\sqrt{N})$ vs classical $O(N)$).

1. Superposition

All 16 states start in equal superposition: a = 1/√16 = 0.25, P = 6.25% each.

2. Phase Oracle (U_w)

U_w |x⟩ = -|x⟩ (target), else +|x⟩

Inverts the marked target's sign, creating phase contrast.

3. Diffusion Operator

a'_i = 2μ - a_i (Reflection about mean amplitude)

Because the target phase was negated, the mean drops. Reflecting about this low mean amplifies the target while suppressing others.

4. Geometric Rotation & Overshoot

P_target(k) = sin²((2k + 1) θ) where θ = arcsin(1/4) ≈ 14.48°
  • k = 0: 6.25% (Superposition)
  • k = 1: 47.27% (First amplification)
  • k = 2: 90.84% (High concentration)
  • k = 3: 96.13% (Optimal Peak!)
  • k = 4: 58.17% (Overshoot Drop!)
  • k = 5: 12.55% (Collapse)
